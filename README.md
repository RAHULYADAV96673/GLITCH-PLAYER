 # GLITCH OS

GLITCH OS is a browser-based Web OS built with **HTML, CSS, and vanilla JavaScript**.

It is designed to feel like a futuristic desktop operating system inside the browser, with a cyber-glass interface, desktop clock, app windows, dock, taskbar, start menu, quick settings, and multiple built-in apps.

Live demo: https://glitchos.netlify.app/

---

## Project Idea

The idea behind GLITCH OS is simple:

> What if a normal web page could behave like a desktop OS?

This project tries to recreate the feeling of Windows, macOS, and Linux inside a browser using only frontend technologies.

No React.  
No Next.js.  
No Tailwind.  
No frameworks.

Only:

- HTML
- CSS
- Vanilla JavaScript

---

## Current Status

This project is still a **work in progress**.

The live version currently includes the main OS shell, desktop layout, Mond-style clock, Start menu, Quick Settings panel, taskbar, and system tray UI.

Some features and apps may not work perfectly yet. This is normal because the project is still being developed and polished.

## Features

### Desktop Interface

- Cyber-glass desktop design
- Futuristic dark wallpaper style
- Desktop clock widget
- Start menu
- Taskbar
- System tray
- Quick settings panel
- Dynamic island notification area
- Desktop app icons
- Dock-style app launcher

---

### Mond-Style Clock

The desktop includes a Rainmeter/Mond-inspired clock widget.

It shows:

- Day
- Date
- Time
- Minimal clean typography
- Desktop widget style

The clock is designed to give the OS a premium desktop look.

---

### Start Menu

The Start Menu acts as the main app launcher.

It includes:

- GLITCH OS branding
- App launcher area
- Power controls
- Sleep / Restart / Shut Down style buttons

---

### Quick Settings

The Quick Settings panel gives the interface a more realistic OS feel.

It includes:

- Wi-Fi toggle UI
- Bluetooth toggle UI
- Theme toggle UI
- Live wallpaper toggle UI
- Volume control
- Brightness control
- Now playing section

Note: These are browser-based UI controls. They do not control the real hardware Wi-Fi, Bluetooth, or battery.

---

### Taskbar

The taskbar includes:

- Start button
- App search area
- Running apps area
- System tray
- Wi-Fi indicator
- Battery-style indicator
- Volume indicator
- Time display
